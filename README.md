## Notion

**Notion** is an all-in-one workspace designed for note-taking, project management, and task organization. It provides a customizable canvas where students can track assignments, build study databases, and manage personal schedules.
### Useful features
**Notes** store lecture notes and study materials
**To do list** Track assignment and task
**Calendars.** Keep track of deadline and important datess

### Why Students Should Use It
- **All-in-One Hub:** Combines notes, docs, task lists, and calendars into a single application.
- **Flexible Databases:** Enables organizing study materials using tables, Kanban boards, and calendar views.
- **Student Plan:** Offers free access to the Personal Pro plan using a valid student email address.
- **Collaborative Work:** Allows sharing pages with classmates for group project planning and shared notes.

### How to Get Started
1. Sign up on the [Notion Website](https://www.notion.so/) using your student email.
2. Select a pre-built template from the **Templates** tab (e.g., *Student OS* or *Class Notes*).
3. Create a main workspace page for your current semester's courses.
4. Add sub-pages for individual subjects to track assignments, reading lists, and lecture notes.

## Canva

**Canva** is an online graphic design platform that allows users to create designs easily without needing advanced design skills. It can be used to create posters, presentations, social media posts, logos, flyers, and many other types of visual content.

### Why Students Should Use It

- It is easy to use, even for beginners.
- It provides many free templates and design elements.
- It can be used to create presentations and school projects.
- It supports collaboration, allowing students to work together on designs.
- It can be accessed through a web browser and mobile app.

### How to Get Started

1. Visit [Canva](https://www.canva.com/).
2. Create a free account or sign in.
3. Choose a template or start a design from scratch.
4. Add text, images, shapes, and other elements.
5. Download or share your finished design.

- [Canva Website](https://www.canva.com/)
